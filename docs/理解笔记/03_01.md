## 归一化回报：不只是“没跌倒”

**把原文文字定义写成辅助公式：**

<a id="E001"></a>

$$
R_{\mathrm{norm}}=\frac{\text{完整回合实际获得的未折扣奖励总和}}{\text{该总和可能达到的最大值}}.
$$

它综合姿态、速度等跟踪质量以及完整回合的执行情况。提前终止通常减少累计奖励，因而得分较低。它不是动作成功率，也不是训练目标中的折扣回报 $J$。

论文另外区分**训练回报**与**保存检查点的评估回报**。训练初始状态由基于回报的重置采样决定，会随训练变化；评估按固定协议执行。因此图 4 的训练回报与检查点评估曲线不能直接混读。

依据：p.6，[S038](../../reader/paper.md#S038)；p.7，[图 4 / C005](../../reader/paper.md#F004)。

## GPU 小时不是实际等待时间

**计算定义：**

<a id="E002"></a>

$$
C_{\mathrm{GPU-h}}=N_{\mathrm{GPU}}\,T_{\mathrm{hours}}.
$$

SONIC 的报告配置为 $128\times168=21504$ GPU 小时，论文取约 21000；SuperMimic 单 GPU 3 小时为 3 GPU 小时。按精确配置相除为 $21504/3=7168$，论文概括约 7200 倍，并采用“超过 1000 倍”的保守主张。等待时间比为 $168/3=56$。

双 GPU 9.8 小时对应 19.6 GPU 小时；不能把它与单 GPU 3 小时当作同一个结果点。所有这些比较还需保留 GPU 型号和数据量差异，见 [03_02](03_02.md)。

依据：p.6，[S040–S041](../../reader/paper.md#S040)。

## 失败数：覆盖多少训练动作

| 策略与训练点 | 129514 个动作中失败数 |
| --- | --- |
| SONIC 已发布检查点 | 179 |
| SuperMimic，单 GPU 3 小时 | 25 |
| SuperMimic，双 GPU 9.8 小时 | 0 |

失败由 SuperMimic 的训练终止条件判断。SONIC 原本使用的成功标准不同，因此“本文统一评估协议下的失败数”与“各方法自己原论文的成功率”不应直接混同。

这些动作也是双方的训练动作；零失败表示这一集合覆盖完整，不构成未见动作泛化结论。也不意味着每个身体部位都与参考逐点完全一致。

依据：p.17–18，[S103–S105](../../reader/paper.md#S103)、[表 A.8](../../reader/paper.md#T009)。

## 世界模型误差：0.007 到底代表什么

图 3(c) 的量是**8 步状态预测误差**，以预定义标称误差归一化，并在线测量策略轨迹。它不是 0.007 m，也不是 99.3% 的准确率；不是公式 (1) 四类误差总和的直接替代。

论文图注没有给出足以还原全部归一化细节的精确计算公式，因此此处不编造范数、平均方式或标称尺度。不同数据规模下策略访问的状态分布也可能不同，应按作者规定的在线测量口径理解趋势。

依据：p.7，[图 3 / C004](../../reader/paper.md#F003)。

## 速度任务的相对稳态误差

**根据原文协议写出的辅助表达式：**

<a id="E003"></a>

$$
e_{\mathrm{rel}}=\frac{\|\mathrm{mean}_{\text{最后2秒}}(\boldsymbol v_{\mathrm{meas}}-\boldsymbol v_{\mathrm{cmd}})\|}{\|\boldsymbol v_{\mathrm{cmd}}\|}.
$$

这里 $\boldsymbol v$ 泛指该指令平面中被评估的速度分量集合，涉及转向的平面也包含偏航角速度；不是仅指平移速度。原文对不同物理量混合时的额外归一化细节未在此明确给出，因而不能补上未经说明的权重。

每个指令持续 5 秒，取最后 2 秒平均误差的范数；先平均再求范数，和先逐时刻求误差范数再平均不同。每个指令做四次试验，汇总未跌倒试验的中位数；四次全跌倒时在图中画到上限 0.9，超过 0.9 的误差也截到该上限。

三个平面各有 $15\times15$ 个格点，排除各平面的零指令，得 $3\times(225-1)=672$ 个阶跃响应。RL 与蒸馏误差中位数分别为 0.16 和 0.49；650 与 15 是“哪一个误差更小”的数量，两项合计为 665；原文另报告蒸馏在 7 个指令上四次全跌倒，但这一段没有完整展开各类计数的口径，因此不自行把其余 7 个标成平局。

依据：p.18–19，[S113](../../reader/paper.md#S113)、[S117–S118](../../reader/paper.md#S117)、[图 7 / C008](../../reader/paper.md#F007)。
